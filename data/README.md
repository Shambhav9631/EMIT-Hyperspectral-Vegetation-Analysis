# Data

This folder is reserved for local input datasets.

Large EMIT hyperspectral datasets are not included in this repository.

Place the required data files in this folder before running the notebooks.

Expected inputs may include:

- EMIT NetCDF reflectance data (`.nc`)
- EMIT ENVI raster data (`.dat`)
- ENVI header files (`.hdr`)
- NDVI raster data (`.tif`)

Check the input path and filename in each notebook before running it.
